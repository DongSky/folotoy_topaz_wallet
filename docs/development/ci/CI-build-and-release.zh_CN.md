# 构建与发布

`.github/workflows/build-firmware.yml` 仅手动触发，将验证过的固件上传为 Actions 产物，不创建 GitHub Release，也不由标签触发。主分支固件检查仍由 `firmware-checks.yml` 执行。

托帕钱包发布前，维护者检查源码和二进制中的个人数据，核对校验值，并明确硬件验证边界。在审核过的提交上创建版本，仅上传检查过的 APK、固件包、清单、脱敏报告及校验值。不得上传设备备份、NVS、个人资料、签名私钥、ELF／MAP 或原始构建／串口日志。

固件包包含供已有身份配置设备使用的分段镜像，以及用于明确完整初始化的合并镜像。每个包必须附带保留数据的刷写说明。实机验收未完成时使用预发布；APK 版本与发布说明应一致，预发布标签可以细分已有开发版本，不必重编已验证的二进制。

创建标签前同步中英文更新日志。禁用标签自动发布，避免 CI 重编产物替换人工检查过的发布附件。
