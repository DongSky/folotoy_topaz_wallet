# 托帕钱包应用

当前实现详见[项目指南](../../README.zh_CN.md)。Android 0.3-dev 保留原包名，以支持兼容升级。助记词使用普通明文多行输入，仅可选 BIP39 密码隐藏显示。

## 架构与兼容性

手机在本机派生 BTC BIP84、EVM BIP44 与 Solana SLIP10 公开地址，查询公开余额／价格 API 并生成设备离线页面。Bitcoin 使用首个收款地址，不扫描整个 HD 账户。助记词和种子不持久化、不传输。原版 BLE 身份从设备已有只读 `cardid` 分区加载，不包含生成的身份或个人初始化数据。

已实现原版资料、图片、内置头像、RTTTL 音乐与截图协议，并与所有者认证的 PCW 快照服务共存。保留 UUID、序列号广播与小程序数据格式，仍须经过未经修改的官方小程序实机测试才能确认兼容。

## 布局与操作

240×320 界面采用深蓝／绿色及有许可证的中文字体。首页为名片／图片，名片内分详情、社交账号、收款码、加密地址及资产。上下选择，OK 进入或显示金额，长按 OK 返回。长按上键开启配对；长按下键并本机确认后重置配对手机。

快照最多 52 页，使用原子双分区存储。新私密页不会继承旧快照的显示授权。原版截图接口拒绝钱包页及配对／重置对话框。

## 固件数据

`partitions.csv` 保留原版 NVS、身份、图片／音频资源位置；钱包双分区从 `0x500000`／`0x660000` 开始，截图缓存从 `0x7c0000` 开始。RTTTL 限制 1,024 字节、十分钟和 0–8 八度。截图使用 40 行分块，避免整屏堆缓存。不得分发包含已初始化身份的 Flash 备份。

## 验证

完整固件／构建和主机检查、62 项 Android 单元测试、10 项 API 35 模拟器测试及 lint 通过；原生 LVGL 检查了字形和截图。此构建仍待真实 BLE／SMP、官方微信小程序、ROM 头像解码、音乐、扫码及运行时堆内存验收。产物标识位于本地且被 Git 忽略的 `dist/manifest.json`，同时提供 SHA-256 校验与刷写说明。
